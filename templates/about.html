Project Goals

This project was built using the Flask framework in Python. It serves as introduction to web development concepts:

  • Routing: Connecting a URL ("/" or "/about") to a specific Python function.
  • Templating: Dynamically injecting Python data (our list of quotes) into static HTML.
  • Server Setup: Running a local web server using app.run(debug=True).

This is the first step toward building more complex, data-driven web applications.
